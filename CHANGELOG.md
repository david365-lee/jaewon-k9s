# Changelog

## 0.1.2

- Simplified local and remote cluster selection into one searchable context picker.
- Refreshed the Docker Desktop UI with clearer context status, a focused launch action, and responsive terminal zoom controls.
- Restarted the K9s terminal session when reconnecting to the selected context.
- Updated the Korean, English, Japanese, and Chinese documentation.

## 0.1.0

- Added local Docker Desktop and remote host-kubeconfig context selection.
- Added container-safe routing for loopback Kubernetes API endpoints while preserving TLS server-name validation.
- Added persisted terminal zoom controls and keyboard shortcuts.
- Added bounded, atomic kubeconfig storage with restrictive file permissions.
- Added Korean and English documentation and reproducible build instructions.
