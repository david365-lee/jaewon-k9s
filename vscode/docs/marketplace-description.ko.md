# Jaewon K9s — VS Code Marketplace 상세 설명

Jaewon K9s는 VS Code 통합 터미널에서 K9s를 실행하고, 실행 전에 로컬 또는 원격 Kubernetes 컨텍스트를 선택할 수 있는 무료 확장입니다. 한국의 개발자 jaewon이 독립적으로 개선하고 무료로 배포합니다.

## 0.1.7 업데이트

Windows에서는 UTF-8 콘솔과 한 칸 테두리 문자 폭을 적용하고 전체 색상을 기본으로 사용합니다. 명령·검색 입력창의 아이콘을 숨기는 K9s `noIcons: true` 설정도 README에 안내합니다.

## 주요 기능

- 로컬·원격 컨텍스트를 하나의 검색 가능한 목록에서 선택하고, 유형·현재 컨텍스트·클러스터·API 주소를 확인합니다.
- 선택한 컨텍스트 이름을 K9s 실행에 명시해 의도하지 않은 기본 컨텍스트 연결을 방지합니다.
- K9s 사이드바의 정밀 확대·축소 영역에서 휠을 움직이면 글꼴 크기가 1px씩 바뀝니다. 작은 입력은 누적하고 빠른 연속 입력은 제한합니다. 숫자 직접 입력과 +/−, 초기화 버튼도 제공합니다. VS Code 기본 Ctrl+휠 확대는 기본값에서 껐습니다. 사용자 설정에서 `terminal.integrated.mouseWheelZoom`을 명시적으로 켰다면 직접 꺼 주세요. 크기 변경은 모든 통합 터미널에 적용됩니다.
- kubectl/K9s 실행 파일 경로와 선택적 kubeconfig를 설정할 수 있습니다.
- 한국어, 영어, 일본어, 중국어 간체로 명령과 설정을 표시합니다.

## 사용 조건

VS Code 1.90 이상, 호스트에 설치된 `kubectl`, K9s 및 사용할 컨텍스트가 필요합니다. K9s와 kubectl은 확장에 포함되지 않습니다. 원격 클러스터 연결은 호스트의 네트워크, VPN, 인증 플러그인 및 자격 증명 설정에 따릅니다.

K9s 사이드바의 정밀 확대·축소 영역에서 휠을 움직이면 글꼴 크기가 1px씩 바뀝니다. 작은 입력은 누적하고 빠른 연속 입력은 제한합니다. 숫자 직접 입력과 +/−, 초기화 버튼도 제공합니다. VS Code 기본 Ctrl+휠 확대는 기본값에서 껐습니다. 사용자 설정에서 `terminal.integrated.mouseWheelZoom`을 명시적으로 켰다면 직접 꺼 주세요. 크기 변경은 모든 통합 터미널에 적용됩니다.

## 개인정보 및 보안

컨텍스트 목록을 호스트에서 조회하며 kubeconfig 내용을 업로드하거나 저장하지 않습니다. 선택된 컨텍스트를 K9s 프로세스에 전달하고, 인증은 사용자의 로컬 Kubernetes 설정에 맡깁니다. 신뢰하는 클러스터에만 연결하세요.

## 작성자 및 라이선스

한국의 개발자 jaewon이 Kubernetes 작업을 조금 더 편리하게 만들고자 독립적으로 개선해 무료로 나누는 확장입니다. 개인·회사 프로젝트에서 자유롭게 사용하실 수 있으며, MIT 라이선스에 따라 소스 코드를 확인하고 수정·재배포할 수도 있습니다. 이 확장은 K9s를 포함하거나 K9s 프로젝트를 대표하지 않습니다. K9s와 Kubernetes의 상표 및 라이선스는 각 소유자에게 있습니다.
