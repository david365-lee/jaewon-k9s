# Jaewon K9s — VS Code Marketplace 상세 설명

Jaewon K9s는 VS Code 통합 터미널에서 K9s를 실행하고, 실행 전에 로컬 또는 원격 Kubernetes 컨텍스트를 선택할 수 있는 무료 확장입니다. 한국의 개발자 jaewon이 독립적으로 개선하고 무료로 배포합니다.

## 주요 기능

- `kubectl`이 제공하는 kubeconfig 컨텍스트를 로컬, 원격/기타, 전체 목록으로 나누어 빠르게 선택합니다.
- 선택한 컨텍스트 이름을 K9s 실행에 명시해 의도하지 않은 기본 컨텍스트 연결을 방지합니다.
- 확대, 축소, 초기화 명령과 Ctrl+마우스 휠 확대/축소를 지원합니다.
- kubectl/K9s 실행 파일 경로와 선택적 kubeconfig를 설정할 수 있습니다.
- 한국어, 영어, 일본어, 중국어 간체로 명령과 설정을 표시합니다.

## 사용 조건

VS Code 1.90 이상, 호스트에 설치된 `kubectl`, K9s 및 사용할 컨텍스트가 필요합니다. K9s와 kubectl은 확장에 포함되지 않습니다. 원격 클러스터 연결은 호스트의 네트워크, VPN, 인증 플러그인 및 자격 증명 설정에 따릅니다.

`Ctrl+마우스 휠` 확대/축소는 VS Code의 `terminal.integrated.mouseWheelZoom` 설정을 활성화하며, K9s 터미널뿐 아니라 모든 통합 터미널에 적용됩니다.

## 개인정보 및 보안

컨텍스트 목록을 호스트에서 조회하며 kubeconfig 내용을 업로드하거나 저장하지 않습니다. 선택된 컨텍스트를 K9s 프로세스에 전달하고, 인증은 사용자의 로컬 Kubernetes 설정에 맡깁니다. 신뢰하는 클러스터에만 연결하세요.

## 작성자 및 라이선스

한국의 jaewon 개발자가 무료로 개선·배포합니다. 확장 소스는 MIT 라이선스이며 K9s를 포함하지 않습니다. 각 프로젝트의 상표와 라이선스는 해당 소유자에게 있습니다.
