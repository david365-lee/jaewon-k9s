# Jaewon K9s — VS Code Marketplace 詳細説明

Jaewon K9s は、VS Code の統合ターミナルで K9s を起動し、起動前にローカルまたはリモートの Kubernetes コンテキストを選択できる無料拡張機能です。韓国の開発者 jaewon が独自に改善し、無料で配布しています。

## バージョン 0.1.9

Windows では UTF-8 と1セル幅の罫線文字を使用し、既定でフルカラー出力を有効にします。コマンド・検索入力欄のアイコンを非表示にする K9s の `noIcons: true` 設定も README で説明しています。

## 主な機能

- ローカルとリモートのコンテキストを1つの検索可能な一覧から選択し、種別、現在のコンテキスト、クラスター、API アドレスを確認できます。
- 選択したコンテキストを K9s に明示して、既定コンテキストへの誤接続を防ぎます。
- K9s サイドバーの精密ズーム領域でホイールを動かすと、フォントサイズが 1px ずつ変わります。小さな入力を蓄積し、連続入力を制限します。数値入力、+/−、リセットも使用できます。標準の Ctrl+ホイールズームは既定で無効です。`terminal.integrated.mouseWheelZoom` を明示的に有効にしている場合は設定で無効にしてください。サイズ変更はすべての統合ターミナルに適用されます。
- kubectl/K9s の実行ファイルと任意の kubeconfig を設定できます。
- 韓国語、英語、日本語、簡体字中国語のコマンドと設定に対応します。

## 必要条件

VS Code 1.90 以降、ホストにインストールされた `kubectl` と K9s、および使用するコンテキストが必要です。K9s と kubectl は同梱されません。リモート接続はホストのネットワーク、VPN、認証プラグイン、認証情報に依存します。

K9s サイドバーの精密ズーム領域でホイールを動かすと、フォントサイズが 1px ずつ変わります。小さな入力を蓄積し、連続入力を制限します。数値入力、+/−、リセットも使用できます。標準の Ctrl+ホイールズームは既定で無効です。`terminal.integrated.mouseWheelZoom` を明示的に有効にしている場合は設定で無効にしてください。サイズ変更はすべての統合ターミナルに適用されます。

## プライバシーとセキュリティ

コンテキストの検出はホスト上で実行されます。拡張機能が kubeconfig の内容をアップロードまたは保存することはありません。選択したコンテキストを K9s に渡し、認証はユーザーのローカル Kubernetes 設定を使用します。信頼できるクラスターにのみ接続してください。

## 開発者とライセンス

この拡張機能は、Kubernetes の日々の作業を少しでも快適にするため、韓国の開発者 jaewon が独自に改善し、無料で公開しています。個人・企業のプロジェクトで自由に利用でき、MIT ライセンスに基づいてソースコードの確認、変更、再配布もできます。K9s は同梱しておらず、K9s プロジェクトを代表するものではありません。K9s と Kubernetes の商標およびライセンスは各権利者に帰属します。
